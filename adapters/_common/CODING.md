# 代码生成统一规则（所有工具）

写进项目后，**任何生成/修改代码**必须遵守：

1. **编码 UTF-8**：所有源码/配置文本文件编码为 **UTF-8**（禁止另存为 GBK/GB2312/UTF-16 等）。
2. **无 BOM**：UTF-8 **without BOM**。禁止写入 UTF-8 BOM / UTF-16 BOM（禁 `EF BB BF` / `U+FEFF`）。
3. **注释无表情**：注释、文档字符串、提交说明里的说明文字**禁止** emoji / 表情符号。可用普通文字：`OK` / `FAIL` / `TODO`。
4. **脚本特例**：`*.ps1` / `*.sh` 保持纯 ASCII、无 BOM；中文说明只放 `.md`（`.md` 同样 UTF-8 无 BOM）。

检测提示：若编辑器或 diff 出现 `U+FEFF` / 文件头 `EF BB BF`，必须去掉再保存。
