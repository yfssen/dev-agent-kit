# 数据库连接与复盘

> 初始化时由 AI **向你索要** MySQL 连接信息后填写。  
> **密码只在 `.env`，禁止写进本文件或其它 Markdown。**  
> 账号通常具备增删改查（全权限）；日常「查状态」仍用只读脚本，写库必须可复盘。

连接自检：

```powershell

```

## 2. 工具分工

| 场景 | 用什么 | 说明 |
|------|--------|------|
| 查状态 / 分析 | `db.ps1` / `db.sh` | **只读单语句**（禁 `;` 多语句） |
| 交互或用户批准的写库 | `mysql.ps1` / `mysql.sh` | 全权限账号；写完必须记入下方复盘 |
| 从连接命令写入 `.env` | `apply-mysql-dsn.ps1` / `.sh` | 初始化用；密码进 `.env` |
