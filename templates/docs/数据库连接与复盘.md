# 数据库连接与复盘

> 初始化时由 AI **向你索要** MySQL 连接信息后填写。  
> **密码只在 `.env`，禁止写进本文件或其它 Markdown。**  
> 账号通常具备增删改查（全权限）；日常「查状态」仍用只读脚本，写库必须可复盘。  
> **纯前端 / 暂无库**：用户回复「无库」后，将下方状态标为跳过即可，不必伪造连接。

## 0. 状态

| 项 | 值 |
|----|-----|
| 状态 | `<已配置 / 跳过（纯前端 / 暂无库）>` |
| 跳过原因 | `<无 / 用户确认无 MySQL / …>` |
| 录入日期 | `YYYY-MM-DD` |

> 状态为「跳过」时：第 1 节可留空或写「N/A」；第 2–3 节待有库后再用。接上后端后重新向用户索要连接并改状态为「已配置」。

连接自检（有库时）：

```powershell
./scripts/db.ps1 "SELECT 1 AS ok"
./scripts/mysql.ps1
```

## 2. 工具分工

| 场景 | 用什么 | 说明 |
|------|--------|------|
| 查状态 / 分析 | `db.ps1` / `db.sh` | **只读单语句**（禁 `;` 多语句）；无库时勿跑 |
| 交互或用户批准的写库 | `mysql.ps1` / `mysql.sh` | 全权限账号；写完必须记入下方复盘 |
| 从连接命令写入 `.env` | `apply-mysql-dsn.ps1` / `.sh` | 初始化用；密码进 `.env` |
